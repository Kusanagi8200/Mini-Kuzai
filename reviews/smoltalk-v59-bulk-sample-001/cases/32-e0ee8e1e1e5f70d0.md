### Turn 2 - ASSISTANT

Here is a 2 and 3 compatible function that converts UNIX time to a human-readable datetime string:

```python
from datetime import datetime
import time

def convert_unix_time_to_datetime(unix_time, utc=False, offset=0):
    if utc:
        unix_time += offset * 3600

    try:
        return datetime.fromtimestamp(unix_time).strftime(&#x27;%Y-%m-%d %H:%M:%S&#x27;)
    except AttributeError:
        return time.strftime(&#x27;%Y-%m-%d %H:%M:%S&#x27;, time.gmtime(unix_time))
```
