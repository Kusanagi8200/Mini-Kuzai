### Turn 2 - ASSISTANT

<pre>
To check if a given matrix is a magic square, we need to follow these steps:

1. Check matrix dimensions: Verify that the matrix is a square matrix; that is, the number of rows and columns is equal.
2. Check row sums: Calculate the sum of elements in each row and check if they are equal to the specified limit. Repeat for columns and diagonals.
3. Check diagonal sums: Calculate the sum of elements in the main diagonal and the secondary diagonal and check if they are equal to the specified limit.
4. Check for non-negative integers: Ensure that all elements in the matrix are non-negative integers.

Here&#x27;s how you can implement this function:

```python
def is_magic_square(matrix, limit):
    rows = len(matrix)
    cols = len(matrix[0])
    if rows != cols:
        return False
    for row in matrix:
        if sum(row) != limit:
            return False
    for col in range(cols):
        col_sum = sum(row[col] for row in matrix)
        if col_sum != limit:
            return False
    main_diag_sum = sum(matrix[i][i] for i in range(rows))
    if main_diag_sum != limit:
        return False

    secondary_diag_sum = sum(matrix[i][cols - 1 - i] for i in range(rows))
    if secondary_diag_sum != limit:
        return False
    for row in matrix:
        for num in row:
            if num &lt; 0:
                return False

    return True
```
