Write a Python function named `replace_chars` that takes two arguments: `string`, a string, and `to_replace`, a list of characters to replace. The function should replace all characters in `to_replace` with underscores (&#x27;_&#x27;), and return the final string.

### Turn 2 - ASSISTANT

<pre>
Here&#x27;s a possible implementation of the `replace_chars` function in Python:

```python
def is_valid_to_replace(string):
    return len(string) &gt; 0 and all(c not in string[i + 1:] for i, c in enumerate(string))

def replace_chars(string, to_replace):
    if not is_valid_to_replace(to_replace):
        return string

    return &#x27;&#x27;.join(&#x27;_&#x27; if c in to_replace else c for c in string)
```
