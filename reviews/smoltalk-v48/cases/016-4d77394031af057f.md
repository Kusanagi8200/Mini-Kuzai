Write a Python function that takes a string containing multiple words separated by whitespace characters as input, and return a list of non-empty substrings that do not contain any whitespace characters. For example, given `input = &quot;This is a sentence.&quot;`, the function should return a list `output = [&quot;This&quot;, &quot;is&quot;, &quot;a&quot;, &quot;sentence.&quot;]`.

You may assume that the input string always starts and ends with a non-whitespace character. The function should also trim the input string, so it starts and ends with non-whitespace characters.
</pre>

### Turn 2 - ASSISTANT

<pre>
Here&#x27;s a simple solution in Python:

```python
def non_whitespace_substrings(input_str):
    words = input_str.strip().split()
    return [word for word in words if word and not word.isspace()]
```

In this implementation, we first use the strip() method to trim the leading and trailing whitespace characters from the input string. Then, we use the split() method to separate the string into a list of words. Finally, we use a list comprehension to filter out any empty strings or strings containing only whitespace characters.
</pre>
