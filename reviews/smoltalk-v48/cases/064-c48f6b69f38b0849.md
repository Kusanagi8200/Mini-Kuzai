If a match is found, we can continue comparing the remaining characters of `t` with the corresponding characters in `s`. If a mismatch is encountered, we can break out of the loop and continue searching for `t` in the remaining part of `s`. If the complete string `t` is found, we return the index where `t` starts in `s`. Otherwise, we return -1 to indicate that `t` is not a substring of `s`.

```python
def find_substring(s, t):
    if not s:
        return -1

    for i in range(len(s)):
        if s[i] == t[0]:
            for j in range(1, len(t)):
                if i + j &gt;= len(s) or s[i + j] != t[j]:
                    break
            else:
                return i

    return -1
```
