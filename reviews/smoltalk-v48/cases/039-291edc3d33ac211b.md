SELECT * FROM employees;
</pre>

### Turn 2 - ASSISTANT

<pre>
You can include an ORDER BY clause in the query to sort the result in descending order. Here is the modified SQL query:

SELECT * FROM employees ORDER BY id DESC;

The ORDER BY clause specifies the column to sort by, in this case, &quot;id&quot;, and the &quot;DESC&quot; keyword is used to sort the result in descending order. By including this clause, the query will return the records from the &quot;employees&quot; table sorted in descending order based on the &quot;id&quot; column.
</pre>
