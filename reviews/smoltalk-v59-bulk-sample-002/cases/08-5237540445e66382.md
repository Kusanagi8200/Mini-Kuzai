<pre>
The Heine-Borel theorem is a fundamental result in real analysis that establishes a key property of compact sets in the Euclidean space. The theorem states that for any subset of the Euclidean space, the following two conditions are equivalent:&#32;

A subset of Euclidean space is compact if and only if it is closed and bounded.

Here, a set is said to be compact if every open cover of the set has a finite subcover. This means that given any collection of open sets that cover the set, we can always find a finite number of these open sets that still cover the entire set.&#32;

A set is closed if it contains all of its limit points, meaning that any point that can be approached arbitrarily closely by points in the set is itself in the set. A set is bounded if it can be contained in a ball of finite radius, meaning that all points in the set lie within some fixed finite distance of a central point.

The Heine-Borel theorem shows that these two seemingly unrelated properties are actually equivalent for subsets of Euclidean space, providing a beautiful connection between the topological and metric properties of these spaces.
