```python
def flatten_dict(d):
    def _flatten_dict(d, parent_key):
        result = {}
        for k, v in d.items():
            key = &#x27;.&#x27;.join([parent_key, str(k)]) if parent_key else str(k)
            if isinstance(v, dict):
                result.update(_flatten_dict(v, key))
            else:
                result[key] = v
        return result

    return _flatten_dict(d, None)
```

In this implementation, we define a nested function `_flatten_dict` to handle the recursion. It takes a dictionary `d` and a `parent_key` as arguments. If `parent_key` is not `None`, it concatenates the parent key with the current key using a dot (&#x27;.&#x27;) to create a dotted key. Then, it checks if the value is a dictionary. If it is, it calls itself recursively to flatten the nested dictionary and updates the result dictionary. Otherwise, it simply adds the key-value pair to the result dictionary. Finally, it returns the result dictionary.

The `flatten_dict` function calls the nested `_flatten_dict` function with the initial `parent_key` set to `None`. This allows us to start the recursion with a clean slate and avoid the need for a separate helper function to concatenate the keys.
