To extract URLs from a text file, we can use the `re` module in Python. This module provides a `findall` function that takes a regular expression pattern and a string and returns all matches. We can use this function to extract all URLs from a text file by reading the file as a string and passing the regular expression pattern to the `findall` function.

Here&#x27;s how we can implement this using the `re` module:

```python
import re

def url_extractor(file_path):
    with open(file_path, &#x27;r&#x27;) as f:
        text = f.read()
    urls = re.findall(r&#x27;https?://\S+&#x27;, text)

    return urls
```

In this implementation, we use the `re.findall` function to find all matches of the regular expression `https?://\S+` in the text file. The dot (.) character matches any character, and the star (*) symbol makes the preceding character or group optional. The `?` character makes the preceding character or group optional and matches zero or one time. The `+` character matches one or more occurrences of the preceding character or group.
