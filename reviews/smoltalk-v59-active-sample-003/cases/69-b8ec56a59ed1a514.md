```python
def convert_to_binary(integers):
    binary_strings = []

    for integer in integers:
        binary_string = bin(integer).lstrip(&#x27;0b&#x27;).rjust(8, &#x27;0&#x27;)
        binary_strings.append(binary_string)

    return binary_strings
```
