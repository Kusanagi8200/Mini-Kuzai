A bar chart or a stacked bar chart might be a better choice to display these results. These types of charts allow for easier comparison of the different categories and can make the relationships between them more apparent. For example, a bar chart could show the percentage of respondents for each category, with the x-axis representing the response categories and the y-axis representing the percentage of respondents. This would make it easier to see the relative proportions of each category and compare them directly.
