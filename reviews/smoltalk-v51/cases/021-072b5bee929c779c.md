To achieve the desired functionality without using any in-built functions, you can import the `re` module and use the `re.findall` function to find matches. The `re.findall` function returns a list of all non-overlapping matches, so to count the number of matches, you can simply take the length of the returned list.

Here is the implementation:

```python
import re

def regex_count(string, pattern, flags=re.I):
    return len(re.findall(pattern, string, flags=flags))
```
