Here&#x27;s how you can implement the function in Python:

```python
def recursive_string_check(list_of_strings, target_string):
    if not list_of_strings:
        return True if not target_string else False
    if not target_string:
        return any(not string for string in list_of_strings)
    return target_string in list_of_strings or recursive_string_check(list_of_strings[1:], target_string)
```
